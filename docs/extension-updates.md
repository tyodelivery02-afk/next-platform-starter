# プラグイン更新

管理画面：`https://deliverylove.netlify.app/extension-updates`

## 公開

1. `GOOGLE_DRIVE_API_KEY` を Netlify の Functions で使用できる環境変数に設定し、この工程をデプロイする。
2. 指定の Google Drive フォルダーへ `caution-bot-2.20.2.zip` のように版数を含む名前で ZIP をアップロードする。
3. 管理画面の「最新版を確認」で版数とファイル情報を登録する。
4. 必要なときに別の「通知を送信」を押す。

保存先：`https://drive.google.com/drive/folders/1niAGjrFlmJjPZMphQfvZ8U2bZorgRymR`

保存先と ZIP は「リンクを知っている全員・閲覧者」で共有し、ダウンロードを許可する。Google アカウントのパスワードや OAuth トークンはプラグインに配布しない。

ZIP は16MB以内。最新版はファイル名の数字を比較して選ぶ。Drive の内部リビジョン番号はプラグインの版数として使用しない。同じ版数の ZIP は一つだけ置き、公開後は上書きせず新しい版数を使用する。

## 通信

Netlify は Drive API からファイル名・ID・所属フォルダー・サイズ・SHA-256 等の JSON だけを取得する。ZIP 本体の取得、アップロード、保存、プロキシ配信は行わない。登録済みのメタデータと通知だけを Netlify Blobs の `caution-bot-releases` ストアに保存する。旧版の ZIP アップロード・配信 API は410を返す。旧方式で既に保存したデータは削除しないが、配信には使わない。

各プラグインの定期確認は登録済み JSON を返すだけで、Drive API を毎回呼ばない。ZIP を Drive に追加した後は管理画面の「最新版を確認」を押す。

確認後の ZIP は Windows 更新プログラムが Google Drive から直接取得する。API キーは Netlify 内だけで使用し、公開 JSON やプラグインに含めない。Drive の共有・確認ページ・一時的な制限によって取得できないときはエラーを表示し、更新しない。

## 初回設定・移行

新しいプラグインを既存フォルダーへ上書きし、Chrome で一度再読み込みする。「更新」→「初回設定」で拡張機能 ID をコピーし、`updater/インストール.vbs` をダブルクリックして ID を貼り付ける。以前の Netlify 配信版を使用した場合も、一度この再設定が必要。フォルダーを移した場合も再設定する。

更新プログラムは Windows 用。ユーザーの LocalAppData と HKCU に登録する。開発者モードで読み込んだ Chrome 拡張機能を対象とする。

版数、サイズ、SHA-256、ZIP 内のパス、manifest のプラグイン名・公開鍵を検証してから置換する。manifest の版数と登録情報が異なる場合は拒否する。失敗時は旧版を復元する。ローカルの設定、配送データ、ゲームデータを更新サーバーへ送信しない。

更新の確認ボタンは「統計」の左。開いたときと30分ごとに確認し、新しい通知は一度だけ自動表示する。登録実行中は表示を保留し、更新を拒否する。実行終了後に通知を表示する。
